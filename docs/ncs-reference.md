**worksim에 대한 함의**
1. 리포트·강사 화면의 역량 라벨을 신 체계 용어로 바꿔야 "NCS 기반"이라는 말이 2026년 이후에도 유효하다.
2. 신설 3개(AI활용·디지털책임·산업안전보건)는 시장에 콘텐츠가 거의 없다. 정부가 워크북을 연내 만든다고 했지만 **시뮬레이션형은 비어 있다.**
3. 공기업 필기는 아직 구 10영역 기준으로 출제 중(2026 하반기 기준). 채용 시장은 1~2년 시차를 두고 따라올 것. **당분간 신구 병기**가 안전하다.

## 1. 신 체계: 직업공통능력 7영역 · 21하위능력

공식 정의 원문은 `[검증필요]`. 아래 "작업 정의"는 구 체계 정의와 개편 취지를 바탕으로 이 프로젝트에서 쓰기 위해 정리한 것.

| # | 영역 | 하위능력 | 작업 정의 | 구 체계 대응 |
|---|---|---|---|---|
| 1 | **의사소통능력** | 1-1 문서소통능력 | 업무 문서를 읽고 핵심을 파악하며, 목적에 맞는 문서를 작성 | 문서이해 + 문서작성 |
| | | 1-2 구두소통능력 | 경청하고, 상황·상대에 맞게 말로 전달 | 경청 + 의사표현 |
| | | 1-3 외국어소통능력 | 업무에 필요한 기초 외국어 문서·대화 처리 | 기초외국어 |
| 2 | **수리능력** | 2-1 연산능력 | 업무 수치를 계산·검산 | 기초연산 |
| | | 2-2 통계활용능력 | 평균·비율·추세 등 기초 통계를 업무 판단에 활용 | 기초통계 |
| | | 2-3 도표활용능력 | 표·그래프를 읽고, 데이터를 도표로 표현 | 도표분석 + 도표작성 |
| 3 | **문제해결능력** | 3-1 문제분석능력 | 문제 상황을 인식하고 원인·구조를 분석 | 사고력(일부) + 문제처리(문제인식·원인분석) |
| | | 3-2 대안발굴능력 | 복수의 해결 대안을 창의적·논리적으로 도출 | 사고력(창의·논리·비판) |
| | | 3-3 의사결정능력 | 기준에 따라 대안을 평가·선택하고 실행·평가 | 문제처리(해결안 개발·실행·평가) |
| 4 | **자기관리능력** | 4-1 경력개발능력 | 자신의 경력 목표를 세우고 개발 전략을 실행 | 경력개발 |
| | | 4-2 적응학습능력 ★ | 변화(기술·조직·직무)에 맞춰 스스로 학습하고 적응 | 신설 (자기관리·자아인식 흡수 추정) |
| | | 4-3 시간관리능력 | 우선순위를 정해 시간을 계획·배분·통제 | 자원관리 → 시간관리 |
| 5 | **대인관계능력** | 5-1 협업능력 | 팀 목표를 위해 역할을 분담·조율하며 함께 일함 | 팀워크 (+고객서비스·협상 일부 흡수 추정) |
| | | 5-2 리더십 | 구성원을 동기부여·조정하고 방향을 제시 | 리더십 |
| | | 5-3 갈등관리능력 | 갈등의 원인을 파악하고 건설적으로 해결 | 갈등관리 (+협상) |
| 6 | **디지털능력** ★ | 6-1 디지털활용능력 | 디지털 도구·데이터로 업무를 수행 | 컴퓨터활용 + 정보처리 + 기술활용 |
| | | 6-2 AI활용능력 ★ | AI 도구에 적절히 위임·지시하고 결과를 검증·활용 | 신설 |
| | | 6-3 디지털책임의식 ★ | 정보보안·개인정보·저작권·AI 윤리 등 디지털 환경의 책임 있는 행동 | 신설 |

## 2. 구 체계: 직업기초능력 10영역 · 34하위능력

공기업 필기·기존 교재·K-CESA 등 **현장은 아직 이 체계를 쓴다.** worksim 아이템 태깅은 신구 양쪽에 걸어두는 것을 권한다.

| 영역 | 정의 | 하위능력 (34) |
|---|---|---|
| 의사소통능력 | 업무 문서·말을 이해하고 자기 의사를 정확히 표현 | 문서이해 · 문서작성 · 경청 · 의사표현 · 기초외국어 |
| 수리능력 | 업무 수치를 계산·해석하고 도표로 다룸 | 기초연산 · 기초통계 · 도표분석 · 도표작성 |
| 문제해결능력 | 창의·논리·비판적 사고로 문제를 인식·처리 | 사고력 · 문제처리 |
| 자기개발능력 | 자신을 이해하고 관리하며 경력을 개발 | 자아인식 · 자기관리 · 경력개발 |
| 자원관리능력 | 시간·예산·물적·인적 자원을 확인·확보·배분 | 시간관리 · 예산관리 · 물적자원관리 · 인적자원관리 |
| 대인관계능력 | 협조적 관계를 유지하고 갈등을 해결 | 팀워크 · 리더십 · 갈등관리 · 협상 · 고객서비스 |
| 정보능력 | 정보를 수집·분석·활용하고 컴퓨터를 사용 | 컴퓨터활용 · 정보처리 |
| 기술능력 | 업무 관련 기술을 이해·선택·적용 | 기술이해 · 기술선택 · 기술적용 |
| 조직이해능력 | 조직의 체제·경영·업무를 이해하고 국제 감각 | 국제감각 · 조직체제이해 · 경영이해 · 업무이해 |
| 직업윤리 | 직업인으로서의 윤리적 태도 | 근로윤리 · 공동체윤리 |

### 2-1. 문제해결능력 하위 요소 상세 (worksim 핵심 축)
- **사고력**: 창의적 사고(발산·수렴, 브레인스토밍) · 논리적 사고(피라미드 구조, So What/Why So) · 비판적 사고(전제 검토, 편향 배제)
- **문제처리 5단계**: 문제 인식 → 문제 도출(구조화) → 원인 분석 → 해결안 개발 → 실행 및 평가
- 문제 유형 분류: **발생형**(이미 터진 것, 원상복구) · **탐색형**(더 잘하기, 개선) · **설정형**(미래 지향, 새 목표)

### 2-2. 자원관리 — 시간관리 핵심 개념
- 긴급도 × 중요도 매트릭스(아이젠하워). worksim의 `urgent`/`importance`가 여기서 온다.
- 시간 낭비 요인: 우유부단, 계획 부재, 과도한 완벽주의, 위임 실패

### 2-3. 대인관계 — 갈등관리·협상
- 갈등 대응 5유형(토마스-킬만): 경쟁 · 회피 · 수용 · 타협 · 협력
- 협상 전략: 협력·유화·회피·강압 / Win-Win 절차

## 3. 신구 매핑 요약 (10 → 7)

```
의사소통(5)  ──────────────▶ 의사소통(3)     문서 2→1, 구두 2→1, 외국어 유지
수리(4)      ──────────────▶ 수리(3)         도표 2→1
문제해결(2)  ──────────────▶ 문제해결(3)     확장: 분석·대안·의사결정으로 분해 ← 평가 정밀도 ↑
자기개발(3) + 자원관리(시간) ▶ 자기관리(3)   자아인식·자기관리 → 적응학습으로 재편(추정)
자원관리(예산·물적·인적) ───▶ 폐지/분산      일부는 의사결정·협업 문항 소재로 흡수 가능
대인관계(5)  ──────────────▶ 대인관계(3)     협상·고객서비스 폐지(협업·갈등관리로 흡수 추정)
정보(2) + 기술(3) ──────────▶ 디지털(3)      AI활용·디지털책임 신설
조직이해(4)  ──────────────▶ 폐지/분산       업무이해 → 직장공동체의식·적응학습 소재로(추정)
직업윤리(2)  ──────────────▶ 직업윤리(3)     산업안전보건의식 신설
```

**설계상 의미**: 개편은 "지식 나열형(경영이해, 기술선택…)"을 버리고 **"행동으로 드러나는 수행 역량"**으로 좁혔다. 시뮬레이션은 지식이 아니라 행동을 관찰하므로, 신 체계가 오히려 worksim 같은 도구에 유리하다.

## 4. 평가 방식 총정리

### 4-1. 채용 필기: 직업기초능력평가 (공기업 NCS 필기)

| 유형 | 특징 | 대응 영역 | 대표 기관 (경향) |
|---|---|---|---|
| **모듈형** | 직업기초능력 학습모듈(교재) 지식 기반. 개념·절차·용어를 물음 | 10영역 전부 가능 | 지식 위주 기관, 중소 공기업 |
| **PSAT형** | 배경지식 불필요, 순수 사고력. 긴 지문·자료·조건 | 언어논리↔의사소통, 자료해석↔수리, **상황판단↔문제해결** | 대형 공기업 (한전·코레일 등) |
| **피듈형** | 모듈 개념을 PSAT식 자료·상황에 얹어 출제. 현재 주류 | 혼합 | 다수 |

- **문항 규모 예시**: 코레일 2024.8~ — 총 70문항/70분 = NCS 30 + 전공 30 + 철도법령 10 (2025 유지). 기관별로 40~60문항/50~70분이 일반적.
- **채점**: 대부분 정답 1개 객관식, 동일 배점 또는 문항별 차등 배점(기관 비공개). 과락(영역별 40% 미만 등) 적용 기관 있음.
- **상황판단(SJT) 문항 구조** — worksim 아이템과 동형이다:
  1. 상황 지문(조직·역할·제약 조건)
  2. 추가 조건(규정 발췌, 일정표, 예산표 등 자료)
  3. 질문: "다음 중 **가장 적절한** 행동은?" / "가장 부적절한 행동은?" / "우선순위가 가장 높은 업무는?"
  4. 선지 4~5개 — 모두 그럴듯하며, 정답은 **규정 준수 + 보고 체계 + 이해관계자 고려 + 시급성**의 균형점
- **채점 변형(민간 SJT)**: 최적/최악 2개 고르기(best/worst), 선지별 가중 점수(예: 최적 +2, 차선 +1, 부적절 −1). worksim의 `score` 방식과 같은 계열.

### 4-2. 채용 면접: NCS 기반 구조화 면접

| 유형 | 방식 | 측정 | worksim 대응 |
|---|---|---|---|
| **경험면접 (BEI)** | 과거 행동 사례를 STAR(상황·과제·행동·결과)로 구조화해 질문. 심층 후속질문 | 역량 보유의 **증거** | 리포트의 "처리한 업무" 로그가 STAR 소재가 됨 |
| **상황면접** | 가상 업무 상황 제시 → "어떻게 하겠는가" | 판단·가치 | 시뮬 본체와 동형 |
| **발표면접 (PT)** | 자료 검토 후 해결안 발표 | 문제해결·의사소통 | 보고서 작성 아이템 |
| **토론면접 (GD)** | 공통 주제로 집단 토론 | 의사소통, 논리, 갈등 조정, 배려 | coworksim 영역 |

- **평가 도구**: 역량별 **행동지표(Behavioral Indicator)** + 척도(보통 5점 BARS). 예) 문제해결 — "원인을 2개 이상 구분해 설명했다 / 대안의 장단점을 비교했다 / 실행 후 점검 계획을 말했다".
- 시사점: worksim의 "최적 행동" 근거를 이런 **행동지표 문장**으로 명시하면 채점 근거가 투명해지고, 대학 담당자가 면접 교육과 연결하기 쉽다.

### 4-3. 교육 현장 진단 도구

| 도구 | 주체·대상 | 구조 | 결과 |
|---|---|---|---|
| **K-CESA** (대학생 핵심역량 진단) | KRIVET·교육부 / 대학생. 대학혁신지원사업·IR센터에서 매년 실시 | **6영역**: 의사소통 · 글로벌 · 대인관계 · 종합적 사고력 · 자원/정보/기술 활용 · 자기관리. 온라인, 일반형·핵심형, 2022년 5판형 | 영역별 점수·전국 비교, 자기계발 가이드. **대학이 사전·사후 데이터로 쓰는 표준** |
| **직업공통능력 인증진단** (TEENUP) | 대한상의·교육부 / **직업계고 3학년 전원**(2026: 59,747명 중 98.28% 참여, 7.7~7.9 시행) | 3개 능력군(기초·업무처리·직장적응) · **5영역**: 의사소통(국어) · 의사소통(영어) · 수리활용 · 문제해결 · 직무적응 | 영역별 **1~5등급** + 우수/보통/기초, 2026년부터 **실물 배지**. 대기업·공기업 채용 연계(korchamhrd) |
| 대학 자체 진단 | 각 대학 CTL (예: 동서울대) | 10영역 진단 → 멘토링 연계 | 사전·사후 비교 |
| 직업기초능력 학습모듈 자기점검 | 산업인력공단 가이드북 | 모듈별 **사전평가 → 학습 → 사후 체크리스트** | 자기보고식 |

**worksim 리포트를 대학이 사려면** K-CESA 6영역 또는 신 체계 7영역 중 하나에 라벨을 맞춰야 한다. 둘은 상당히 겹친다(의사소통·대인관계·자기관리·사고력 ≈ 문제해결·자원정보기술 ≈ 디지털).

### 4-4. 성취 수준 체계 (KRIVET)

직업기초능력 성취기준 연구(KRIVET)는 **5단계 숙달 수준**을 제시한다:

| 수준 | 명칭 | 의미(요약) |
|---|---|---|
| 1 | 초보 | 지시가 있어야 단순 과제 수행 |
| 2 | 준비 | 익숙한 상황에서 정해진 절차로 수행 |
| 3 | 적응 | 일반적 업무 상황에서 자율적으로 수행, 예외는 도움 필요 |
| 4 | 숙련 | 복잡·비정형 상황에서도 안정적으로 수행, 타인 지도 가능 |
| 5 | 전문 | 새로운 기준·방법을 만들고 조직에 확산 |

worksim의 A~F 등급을 이 5수준에 대응시키면 "등급"이 아니라 **"수준 진단"**이 되어 교육적 언어로 바뀐다. (A≈4~5, B≈3, C≈2~3, D≈2, F≈1)

## 5. 역량을 "상승시키는" 방식 — 교수·학습 근거

1. **학습모듈 순환**: 사전평가(자기점검) → 개념 학습 → 사례·활동 → 사후 체크리스트. 공단 가이드북의 기본 구조. 시뮬은 이 순환을 **한 세션 안에서** 돌릴 수 있다(worksim의 "세션 성장 곡선"이 정확히 이것).
2. **PBL(문제중심학습)** 효과: 문제해결능력 향상, 특히 **자신감·자기통제** 하위요소에서 유의미한 증진 보고. 의사소통 교과(발표와 토론)에서도 PBL 적용 효과 연구 존재. → 시뮬 뒤에 **디브리핑(성찰) 단계**를 두는 것이 효과의 핵심. 강사 코멘트(`rpDebrief`)를 구조화하라.
3. **수행 중심(performance-based) 전환**: 원광대 사례 — "무엇을 배웠나"가 아니라 **"어떻게 수행할 수 있나"**를 설명하게 하는 교육 구조. 산업체 프로젝트 병행. 시뮬 → 실제 과제로 이어지는 **브릿지 설계**가 대학 영업 포인트.
4. **효과 검증 설계**(대학 보고서용): 사전-사후 **대응표본 t검정**, 가능하면 실험/통제 **준실험설계**. 효과 크기(Cohen's d) 보고. → worksim은 **1회차/2회차 플레이 비교** 또는 **K-CESA 사전·사후**와 짝지어 데이터를 내보낼 수 있어야 한다.
5. **SJT 훈련 원리**: 상황판단은 지식이 아니라 **암묵지(조직 규범·우선순위 감각)**. 향상 방법은 (a) 다양한 상황 노출, (b) 선택 직후 **근거 있는 피드백**, (c) 유사 상황 재노출(전이). worksim 아이템은 이 3요소를 모두 가지고 있으나 (c) 재노출 설계가 약하다.
6. **행동지표 기반 피드백**: "잘했다/못했다"가 아니라 "이 행동지표를 충족했다/못했다". 학습자가 다음에 무엇을 바꿀지 알게 된다.

### 6-3. 검증 체크리스트 (보강 작업 순서)

- [ ] **아이템 태깅**: 모든 `items`에 `ncs: ['3-3','4-3']` 형태로 신 체계 코드, `ncsOld: [...]`로 구 체계 코드를 붙인다. → 리포트에서 하위능력별 점수 자동 집계 가능
- [ ] **최적 행동의 근거 명문화**: 각 아이템의 `best`에 `why` 필드로 **행동지표 문장** 추가 ("규정 위반 소지를 상급자에게 먼저 보고했다" 등). 피드백 화면과 강사 화면에 노출
- [ ] **라벨 교체**: 리포트 6역량 명칭을 신 체계 용어로 (예: "위임과 자원 배분" → "협업·의사결정(위임)"). 괄호로 구 용어 병기 1년
- [ ] **등급 → 수준**: A~F를 KRIVET 5수준 언어로 병기 ("B 등급 · 적응 수준")
- [ ] **대안발굴 측정 추가**: 최소 1개 아이템에 "대안을 2개 이상 제시" 서술형 + AI 채점 → 3-2 커버
- [ ] **SJT 채점 정교화**: 현재 `score` 단일값 → 선지별 `{best, acceptable, poor, harmful}` 4단계로. 필기형 SJT와 정합
- [ ] **재노출 설계**: 초반에 틀린 유형을 오후에 변형 상황으로 다시 출제(전이 측정). 성장 곡선의 근거가 됨
- [ ] **데이터 export**: 학생별 하위능력 점수 CSV/JSON 내보내기(강사 화면) → 대학의 사전·사후 t검정에 바로 쓰이게
- [ ] **K-CESA 크로스워크 표** 1장: 대학 담당자용 "worksim 역량 ↔ K-CESA 6영역 ↔ 직업공통능력 7영역"
- [ ] **편향·타당도 점검**: 직급 가중치(`RANKS[].weights`)의 근거 문서화, 여성/남성 NPC 역할 분포, 문화(`CULTURES`)별 정답 차이의 정당성
- [ ] **원문 대조** `[검증필요]` 항목: ncs.go.kr `직업공통능력 표준_최종.pdf`에서 21하위 공식 정의·수행준거 확보 후 §1 갱신

## 7. 콘텐츠 기획 렌즈

### 7-1. 하위능력 × 상황 매트릭스로 시나리오 뽑기
행(21 하위능력) × 열(상황 유형: 발생형/탐색형/설정형 문제, 대인 갈등, 규정 충돌, 정보 부족, 시간 압박, 윤리 딜레마)의 셀마다 "이 능력이 드러나는 순간"을 한 줄로 쓰면 아이템 초안이 된다. 한 아이템은 보통 2~3개 하위능력에 걸친다 — 주(主) 1개, 부(副) 1~2개로 태깅.

### 7-2. 신설 3개 = 빈 시장
- **6-2 AI활용능력**: AI에게 무엇을 맡기고, 결과를 어떻게 검증하고, 어디서 사람이 책임지는가. "AI 동료" NPC 구조로 구현 가능. 환각·오래된 규정·개인정보 유출·과잉 의존이 오답 축.
- **6-3 디지털책임의식**: 개인정보 포함 첨부 전달, 메신저 캡처 유출, 공용 PC 로그아웃, 저작권 이미지 사용, 딥페이크 의심 자료. 사무실 배경에서 바로 가능.
- **7-3 산업안전보건의식**: 사무실보다 현장(제조·물류·실험실·조리). 중대재해처벌법 이후 대학 이공계·직업계고 수요. 3D 강점이 가장 크게 살아나는 영역.

### 7-3. 평가 도구와 짝짓기
콘텐츠를 만들 때 "이건 어느 평가와 연결되나"를 처음부터 정한다: 공기업 필기 SJT 대비형 / 면접 STAR 소재형 / K-CESA 사전·사후형 / 인증진단(직업계고) 대비형. 연결 대상이 곧 **구매 부서**다.
